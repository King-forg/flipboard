# flipboard
The files to my flipboard project on Stardance!

The hardware used:

Power Distribution Board IA005
Self-Locking Button Switch IA006
Potentiometer Board
N20 Dual Shaft Worm Gear Motor LA009
m2.6 self tapping screws
Green PLA Basic - Bambu

All availiable on bambu store (and makers supply)

Currently, The power distribution board is screwed in with self tapping screws (yikes i know), the other parts aren't screwed in currently. I might fix this. All the power stuff works and is functional.
